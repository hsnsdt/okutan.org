# okutan.org

Sedat Okutan'ın kişisel geliştirici sitesi. Tek sayfa, framework yok: `index.html` + `assets/`.

- `index.html` — ana sayfa (TR/EN, açık/koyu tema)
- `404.html` — hata sayfası (`.htaccess` ile bağlı)
- `og.png` — paylaşım görseli · `llms.txt` — yapay zeka özeti · `sitemap.xml`, `robots.txt`
- `assets/` — logo, fontlar (kendi sunucumuzdan), ekran görüntüleri, profil görselleri
- `github-profile/` — github.com/hsnsdt profil README'si (siteye yüklenmez)

**Yayın:** `main` dalına push → GitHub Actions FTP ile cPanel'e yükler (`.github/workflows/deploy.yml`).
`.htaccess` otomatik yüklenmez; elle yüklenir. İçindeki yönlendirme kuralı, üst klasördeki (ana cPanel hesabı) kuralların okutan.org'u bozmasını engeller.
`kelimeler/` — Kelimeler oyununun sitesi (aynı tasarım dili, oyunun lavanta/mor paleti). APK dosyaları repoda değildir; sunucuda elle güncellenir.
`balon/` — Balon Patlat (HTML5 canvas oyunu) + `balon/api/` PHP/MySQL liderlik tablosu. Veritabanı bilgileri `balon/api/config.php` içinde; bu dosya depoda yok (şablon: `config.sample.php`), sunucuya elle yüklenir. Tablolar ilk istekte otomatik oluşur, eski kurulumlara eksik sütunlar kendiliğinden eklenir. PWA: `balon/manifest.json`, `balon/sw.js` (oyun.js sürümü değişince sw.js içindeki `CACHE` ve `CORE` listesini de güncelle).

**Balon Patlat yönetimi ve testler**
- Yönetim paneli: `/balon/yonetim/` — şifre `balon/api/config.php` içindeki `admin_pass` (boşsa panel kapalı). Şüpheli skorları onaylama/silme, isim engelleme, 30 günlük grafik.
- Paylaşım önizlemesi: `/balon/meydan.php?id=…` (meta etiketleri) + `/balon/api/og.php?id=…` (GD ile skor görseli; font: `balon/api/fonts/InterTight-ExtraBold.ttf`, OFL). GD yoksa genel `og.png` kullanılır.
- Testler (yerelde PHP + MySQL açıkken): `BASE=http://127.0.0.1:8765/balon ADMIN_PASS=... node --test tests/api.test.mjs`. Canlı sitede çalıştırma.
- Yerel sunucu: `php -d extension=gd -S 127.0.0.1:8765 -t .` (XAMPP).

`101-okey/` — 101 Okey (botlara karşı). Kurallar ve botlar `101-okey/okey-motor.js` içinde (arayüzden bağımsız), arayüz `okey.js`. Motor testleri: `node --test tests/okey.test.mjs`.
101 Okey API: `101-okey/api/` (veritabanı ayarı Balon ile ortak, `balon/api/config.php`). Online masada oyunu masa sahibinin tarayıcısı yönetir; sunucu hamleleri ve durumu aktarır. API testleri: `node --test tests/okey-api.test.mjs`. PWA: `101-okey/manifest.json`, `101-okey/sw.js` (okey.js sürümü değişince CACHE/CORE güncellenir).
Okey (düz): `okey/` — kural motoru `okey/motor.js` (testler: `node --test tests/duz-okey.test.mjs`), arayüz `okey/oyun.js`. API `okey/api/index.php` 101 Okey API'sini `OKEY_GAME=okey` ile çağırır; tablolar ayrı (`oy_*`). PWA: `okey/manifest.json`, `okey/sw.js` (oyun.js sürümü değişince CACHE/CORE güncellenir).
Masa sohbeti (yalnızca online masa, iki okey oyunu ortak): `assets/okey-sohbet.js`; API `?a=t_say` / `?a=t_chat` (140 karakter, küfür maskelenir, hız sınırı), tablo `ok_chat` / `oy_chat`.
Ateş ve Su: `ates-ve-su/` — iki kişilik ateş-su bulmaca-platform oyunu, 100 bölüm (5 dünya × 20). Fizik ve kural motoru `ates-ve-su/motor.js` (`window.KorDamla`), bölümler `ates-ve-su/bolumler.js` (`window.AtesSuBolumler`; 34×21 karakter haritası + düğme/kol/platform/kutu listeleri), arayüz `ates-ve-su/oyun.js` (canvas 1088×672). İlk 6 bölüm elle yapıldı; 7–100'ü `node tools/ates-ve-su-bolumler.mjs` üretir (tohumlu, her bölüm çözücüden geçer; dosyayı yeniden yazar). Testler: `node --test tests/ates-ve-su.test.mjs` (`FULL=1` ile hepsi). Online: `ates-ve-su/api/index.php` 101 Okey API'sini `OKEY_GAME=kor` ile çağırır (tablolar `kd_*`); iki tarayıcı `?a=t_sync` ile ~7 kez/sn kendi karakter durumunu yazar, öbürününkünü okur (ok_private koltuk 10/11). Masayı kuran Ateş, katılan Su. `?test=1` yalnızca yerel deneme için `window.__kd` açar, `&dpr=N` çizim çözünürlüğünü artırır.
Gizli Kelime: `gizli-kelime/` — kural motoru `gizli-kelime/motor.js` (testler: `node --test tests/gizli-kelime.test.mjs`), kelime listesi `gizli-kelime/sozluk.js` (CEVAP: elle seçilmiş sık kelimeler; GECERLI: Kelimeler sözlüğündeki 5 harfli kelimeler), arayüz `gizli-kelime/oyun.js`. Sunucu yok; ilerleme ve istatistik localStorage'da (`gk_*`). Günün kelimesi: `dailyAnswer` sabit tohumla karıştırılmış listede gün numarasıyla ilerler (1. gün 2026-11-18, Europe/Istanbul). PWA: `gizli-kelime/manifest.json`, `gizli-kelime/sw.js`.
Tavla: `tavla/` — kural motoru `tavla/motor.js` (testler: `node --test tests/tavla.test.mjs`), arayüz `tavla/oyun.js`. API `tavla/api/index.php` 101 Okey API'sini `OKEY_GAME=tavla` ile çağırır; tablolar `tv_*`, masa iki kişilik. Sohbet ortak modülden (`assets/okey-sohbet.js`).

Kelime Bulucu: `kelime-bulucu/` — Türkçe kelime bulucu (harflerden, kalıpla, Wordle yardımcısı, geçerli mi?), Scrabble puanları (`motor.js`/`ortak.js`/`ortak.php` aynı tablo; test denetler), torba süzgeci, günün kelimesi, telefonda sabit arama çubuğu. Araç sayfası statik: `index.html`, `bulucu.js` (arayüz), `motor.js` (`window.KelimeBulucu`, testler `node --test tests/kelime-bulucu.test.mjs`), `ortak.js`, `kb.css`, PWA `manifest.json`/`sw.js` (yalnızca araç; PHP sayfalarına karışmaz).
Kelime ve liste sayfaları PHP: `/kelime-bulucu/kelime/<adres>/` → `kelime.php` (anlamlar, köken, örnekler, hece, puan, torba, türetilen, anagram, benzer, ilgili listeler), `/kelime-bulucu/liste/<adres>/` → `liste.php` (harfle başlayan/biten/içinde geçen, harf sayısı, birleşimleri, en yüksek puanlılar, değerli harfli kısa kelimeler), ortak kod `ortak.php`, paylaşım görseli `og.php?k=<adres>` (GD; önbellek `veri/og/`, depoda yok). Kök `.htaccess` kuralları yönlendirir. Adreslerde Türkçe karakter yok (ç→c …, çakışanlar `-2/-3`); eski Türkçe karakterli adresler 301 ile yönlenir.
A–Z sözlük dizini: `/kelime-bulucu/sozluk/<harf>/<sayfa>/` → `sozluk.php` (harf adresi ASCII: ç → c-2 …; sayfa başına 200 kelime). Tahta çözücü: `kelime-bulucu/tahta/` (statik; motor `tahta-motor.js` = `window.KBTahta`, hesap Web Worker `tahta-isci.js`, arayüz `tahta.js`; testler `node --test tests/kelime-bulucu-tahta.test.mjs`). Popüler aramalar: `api.php` (`?a=say` POST, `?a=populer`; kimlik/IP tutmaz, günlük sayaç `veri/arama/`). Disk önbelleği: liste ve sözlük sayfaları `veri/onbellek/` (sürüm değişince kendiliğinden yenilenir). `veri/og`, `veri/onbellek`, `veri/arama` sunucuda oluşur, depoda yok; `.htaccess` son ikisini dışarıya kapatır. Telaffuz: Vikisözlük'teki ses kayıtları Wikimedia Commons'tan çalınır. IndexNow: anahtar dosyası kökte (`610356dc09b83793bcbe941706bbe023.txt`), gönderme `node tools/indexnow.mjs`.
Veri üretimi: `python -I tools/vikisozluk-anlam.py` (Vikisözlük dökümünden `tools/.veri/vikisozluk.json`; kaynak `../kelimelik/scripts/trwiktionary-latest-pages-articles.xml.bz2`) sonra `node tools/kelime-bulucu-uret.mjs` → `sozluk.txt`, `anlam/*.json` (ilk anlam, araçtaki pencere), `veri/anlam/*.json` (zengin), `veri/listeler.json`, `veri/sik.txt`, `veri/gunluk.txt`, `sitemap.xml` + `sitemap-kelime-N.xml`, araç sayfasındaki `<!--LISTE-->` bölümü. Kaynak sözlük `../kelimelik/assets/words/`.
